# mock-terminal
mock WSL terminal
## Current features
### username and hostname can be customised
### PNG images can be download for easy use
### multiple commands pairs - input and output can be entered by the user beforehand and rendered all at once, giving the impression that the user had a proper session executing the commands
## Limitations
### no backend, entirely reliant on client side refreshing the page will clear everything
## Upcoming features
### customizable file path in top bar
### full screen PNG download - currently renders only cropped images
### hover to find button use
### more realistic top bar design with actual width, size replication
